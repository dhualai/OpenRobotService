## 四、回归教训

这条链路前后被 AI 检视抓出 5 处问题，全部属于「换实现时丢了原实现的保护」：

1. 环境变量名不一致 → 功能不可用
2. 项目匹配校验丢失 → 门禁被削弱
3. 默认监听 `0.0.0.0` → 凭据明文暴露
4. `eligible` 只写不判 → 绿灯但没验
5. `DISABLED` 提前返回排在 API 之前 → 门禁空转

共同点：**都不报错，只是静默变宽松**。所以本表的存在意义是——任何替换实现的 PR，先列契约，再逐条验证，最后把没验证的写清楚。
