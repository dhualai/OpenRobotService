# Test Gate 必跑套件验收判定

现有 Test Gate 为四个必跑套件生成 JUnit。汇总只统计 Allure 已收到的文件，单个套件全部跳过或缺少产物时，其他套件的结果仍可能使摘要显示没有失败。

框架与基础设施、Mock API、真实后端 Smoke 和 OpenAPI 契约属于必跑范围。它们各自需要 JUnit 和可读的 Allure 用例结果。DB 集成与工单场景沿用观察模式，继续进入诊断报告。

有失败的用例记录时显示失败。必跑套件的 job 被取消或跳过、JUnit 无执行用例、产物缺失或不可读时显示未验收。未验收优先作为整次门禁结论，各套件仍显示各自结果。汇总作业生成可用报告后，使用门禁判定退出。

如果 GitHub Actions 在整次运行被取消后没有调度汇总作业，运行页会保留 GitHub 自身的取消状态。

## 本地验证

报告、客户端、断言、Mock 和业务 API 回归合计 215 条通过。已生成 Allure 和业务 HTML。新增回归验证了部分跳过仍可通过，以及全部跳过、取消、缺少或损坏 JUnit 和 Allure 时显示未验收。另验证了判定失败后仍能整理现有报告产物，以及工作流最后一步会执行门禁退出判定。
