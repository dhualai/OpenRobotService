# 后台管理模块 - 业务分析

## 1. 功能点

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 工单管理 | 查看全部工单列表 | P0 |
| 工单统计 | 工单数据统计 | P0 |
| 看板 | 工单看板概览 | P0 |
| 用户管理 | 用户列表/创建/更新/删除 | P1 |
| 角色管理 | 角色列表/创建/更新/删除 | P1 |
| 项目管理 | 项目列表/创建/详情 | P1 |
| 风险管理 | 项目风险列表 | P2 |
| 日报/周报 | 生成数据分析报表 | P1 |
| 数据导出 | 工单数据导出为 Excel | P2 |
| 资源管理 | 资源列表/创建/详情 | P1 |
| 仪表盘 | 工单数据概览 | P2 |
| 待审批上报 | 审批上报列表 | P2 |
| AI 风险分析 | AI 自动风险识别 | P2 |

## 2. 业务流程

```
管理员登录 -> 仪表盘概览 -> 工单管理(列表/统计/看板)
  -> 项目管理(列表/创建/详情) -> 风险列表 -> AI 风险分析
  -> 用户管理(CRUD) -> 角色管理(CRUD)
  -> 日报生成 -> 数据导出
```

## 3. 状态流转

后台管理模块无状态机。项目、风险、资源等实体由后端管理。

## 4. 权限控制

| 角色 | 可操作 |
|------|-------|
| admin | 全部后台接口可访问 |
| engineer | 不可访问后台接口(403) |
| customer | 不可访问后台接口(403) |
| 无 token | 401 未认证 |

## 6. 风险点

| 风险 | 等级 | 影响 | 建议处理 |
|------|------|------|---------|
| 仪表盘数据性能 | P1 | 大数据量加载慢 | 分页加载或缓存 |
| 导出超时 | P2 | 大数据导出超过 HTTP 超时 | 异步导出+通知下载 |
| 重复项目名称 | P1 | 同名项目混淆 | 后端重复校验 |
| 重复用户名 | P1 | 用户无法注册 | 唯一约束+409 |
| 角色权限不一致 | P1 | 权限验证绕过 | 角色变更后刷新缓存 |
| 资源权限 | P1 | 非法访问他人资源 | 权限校验 |
| 并发项目操作 | P2 | 多个管理员同时编辑 | 乐观锁 |
| 删除用户关联数据 | P1 | 级联数据丢失 | 软删除或确认提示 |

## 7. 边界条件

| 条件 | 说明 | 预期行为 |
|------|------|---------|
| 用户名为空 | 必填字段缺失 | 422 |
| 邮箱格式非法 | 格式校验 | 422 |
| 用户 ID 不存在 | 更新/删除不存在的用户 | 404 |
| 角色名称重复 | 唯一约束 | 409 |
| 角色权限列表为空 | 无权限角色 | 400 |
| 项目 ID 不存在 | 获取不存在的项目详情 | 404 |
| 项目名称为空 | 必填字段缺失 | 422 |
| 日报类型为空 | 不传 type 参数 | 200，默认为 daily |
| 日报类型无效 | 传递不支持的类型 | 422 |
| 资源列表为空 | 没有资源时查询 | 200 [] |
| 用户列表为空 | 无用户时查询 | 200 [] |
| 导出数据为空 | 没有数据可导出 | 生成空文件 |
| 资源 ID 不存在 | 获取不存在的资源 | 404 |
