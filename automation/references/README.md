# references/ - 原始文档库（输入资料）

存放**外部输入**的原始文档，供测试分析与用例设计参考。格式不限（md / xlsx / docx / pdf / openapi.json）。

| 目录 | 内容 |
|------|------|
| `prd/` | 产品需求文档（需求评审稿、需求变更记录） |
| `api/` | 接口文档（openapi/swagger 契约、接口说明） |
| `cases/` | 原始测试用例（人工编写，与自动化执行数据分离） |

## 与相关目录的分工

| 目录 | 定位 | 谁维护 |
|------|------|--------|
| `references/` | 原始输入资料（人读，不参与测试执行） | 测试团队 |
| `testdata/cases/` | 自动化执行用例（机器读，Excel 数据驱动） | 自动化脚本 |
| `docs/` | 测试团队知识库（分析/场景/工作记录） | 测试团队 |

> 仓库根 `docs/` 的全项目共用文档（如 PRD.md）与这里独立存放，互不覆盖；
> 若同一文档两边都有，以更新的为准。
