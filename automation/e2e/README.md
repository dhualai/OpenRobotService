# e2e/ — 端到端测试模块

## 职责
- 编排跨模块的关键业务流程（如：微信报障 → AI 预处理 → 创建工单 → 入库 → 后台可见）。
- 默认标记为 @pytest.mark.slow + @pytest.mark.e2e，仅在 Full Lane 或手动触发时执行。

## 结构
| 目录/文件 | 说明 |
|-----------|------|
| conftest.py | 组合 Fixture（API + DB + Mock 上下文编排） |
| lows/ | 可组合的业务流步骤函数/类 |
| 	ests/ | E2E 测试用例，组装 flow 步骤为完整业务流程 |

## 原则
- 每个 flow 步骤可独立测试
- tests/ 中的用例仅编排步骤顺序，不包含业务断言
