# 机器人操作手册示例

## 1.1 开机操作

步骤：
1. 确认急停按钮已释放
2. 找到控制柜上的红色电源开关
3. 长按开关 3 秒，直到指示灯变绿
4. 等待系统自检完成（约 10 秒）

注意事项：
- 首次开机前请确保已充电 2 小时以上
- 开机时急停必须处于释放状态
- 如果指示灯为红色闪烁，请联系售后

## 1.2 关机操作

步骤：
1. 确认机器人已停止所有任务
2. 长按红色电源键 5 秒
3. 等待指示灯熄灭
4. 关闭总电源开关

注意事项：
- 关机前务必让机器人完成当前任务
- 紧急情况可立即按急停，再执行关机

## 2.1 充电操作

步骤：
1. 将充电线插入机器人底部的充电接口
2. 确认充电桩指示灯变蓝
3. 等待充电完成（指示灯变绿）
4. 断开充电线

注意事项：
- 建议电量低于 20% 时及时充电
- 充电时不要启动机器人
- 长时间存放时保持电量在 50% 以上

## 3.1 网络配置

步骤：
1. 进入【系统设置】→【网络】
2. 选择 WiFi 或有线网络
3. 输入网络名称和密码
4. 点击连接

注意事项：
- 确保网络信号稳定
- 有线网络优先于 WiFi
- 配置完成后记得保存

## 3.2 充电策略配置

步骤：
1. 进入【系统设置】→【电源管理】
2. 选择【充电策略】
3. 设置闲时充电阈值（如 30%）
4. 设置快充/慢充模式
5. 保存并重启

注意事项：
- 闲时充电阈值：电量低于此值时自动开始充电
- 快充模式会缩短电池寿命
- 建议日常使用慢充模式

## 4.1 急停操作

步骤：
1. 发现异常时，立即按下急停按钮
2. 机器人将立即停止所有运动
3. 检查并排除故障
4. 故障排除后，旋转急停按钮释放

注意事项：
- 急停是最高优先级安全功能
- 任何紧急情况第一时间按急停
- 释放急停前确保安全

## 5.1 固件升级

步骤：
1. 准备 U 盘，格式化为 FAT32
2. 下载最新固件到 U 盘根目录
3. 插入机器人的 USB 接口
4. 进入【系统设置】→【固件升级】
5. 选择 U 盘中的固件文件
6. 点击升级，等待完成

注意事项：
- 升级过程中不要断电
- 升级失败可重新升级
- 升级完成后记得重启
