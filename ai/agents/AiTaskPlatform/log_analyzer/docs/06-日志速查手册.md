# 06 - 日志速查手册

> 按字母序排列所有关键日志字符串，每条给出：日志原文 → 含义 → 代码文件:行号

## 使用方式

1. 拿一条日志，Ctrl+F 搜索关键词
2. 找到对应条目，看含义和代码位置
3. 跳到对应服务的详细文档进一步排查
