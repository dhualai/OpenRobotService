# usp-services 问题排查文档

> 面向 **日志排查 Agent** 的文档体系。每份文档从日志视角描述服务的内部运行逻辑、关键日志含义、常见异常及排查路径。

## 如何使用

1. **不知道问题在哪** → 先看 [07-常见故障场景](./07-常见故障场景.md)，按症状匹配排查路径
2. **知道是哪个服务** → 直接看对应服务的文档
3. **手头有一条日志不明含义** → 查 [06-日志速查手册](./06-日志速查手册.md)
4. **想了解系统全貌** → 从 [00-架构总览](./00-架构总览.md) 开始顺序阅读

## 系统概要

本项目是 **统一调度平台 (USP)** 的算法服务层，负责仓库/工厂中 AGV/AMR 机器人的调度：

- **5 个 Ray Actor** 组成分布式核心
- **Flask HTTP API** (端口 6100) 对外暴露所有 REST 接口
- **依赖 6+ 个 usp_algorithm_* 算法包**
- 配置文件：`configs/config.ini` (生产) / `configs/dev_config.ini` (开发优先)
