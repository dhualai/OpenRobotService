## 7. 项目现场信息（排查按需取用）

做成能力 `project_info`，不做子 Agent。现场档案是当前快照，选组和脱敏都在程序里做完再交给调度。子 Agent 会把树交回模型，口令更容易漏进去。

只读 `project_info_node` 与 `project_info_value` 的当前行。不读 `project_info_value_history`，不读 `project_info_node_mark`。

| 项 | 状态 |
|----|------|
| 能力注册，工单有 `project_id` 才可派 | **已落地** |
| 讨论入口只放已填组目录，不放字段值 | **已落地** |
| 调度目标点名后才展开该组 | **已落地** |
| 用户说「项目信息 / 现场信息」时展开已填字段，不再只回目录 | **已落地** |
| 口令、远程码、手机电话、license 正文不进文本 | **已落地** |
| 公网地址和远程入口只说明已配置，不写 IP / 端口 / 远程码 | **已落地** |
| 附件只写「已上传附件」，不写存储路径 | **已落地** |
| 停用节点、空值不出现；项目自定义字段跟着父组走 | **已落地** |
| 单次输出上限约 2400 字，同一轮最多调 3 次 | **已落地** |

可以给排查用的组：项目基础、车型与载具、车端软件、调度软件、网络（仅有无外网一类）、服务器部署形态、现场环境、业务系统、业务流程、项目人员、风险与注意、项目定制。
