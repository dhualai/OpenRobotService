# 观测编码规格

> 给研发落地：表、埋点、计算接口、页面模块、验收。先读 [观测层](./07-bridge.md) 与 [事实抽象](./09-fact.md)。

---

## 1. 最小数据模型

### 任务

| 字段 | 类型 | 说明 |
|------|------|------|
| task_id | 字符串 | 主键 |
| run_id | 字符串 | 所属运行 |
| released_at | 时间戳 | 发布时间 |
| deadline_at | 时间戳，可空 | 截止时间 |
| assigned_at | 时间戳，可空 | 分配成功 |
| completed_at | 时间戳，可空 | 完成 |
| cancelled_at | 时间戳，可空 | 取消 |
| status | 枚举 | 已发布 / 已分配 / 执行中 / 已完成 / 已取消 / 失败 |
| payload_qty | 数值，可空 | 按搬运量计吞吐时用 |
| agent_id | 字符串，可空 | 执行车辆 |

### 运行

| 字段 | 类型 | 说明 |
|------|------|------|
| run_id | 字符串 | 主键 |
| source | 枚举 | 算法仿真 / 系统仿真 / 现场 |
| started_at | 时间戳 | 开始 |
| ended_at | 时间戳，可空 | 结束；进行中可空 |

### 考察时间段

查询参数即可，不必单独建表。

| 字段 | 说明 |
|------|------|
| run_id | 在哪次运行上考察 |
| window_type | 墙上时钟 / 整次运行 / 任务批推导（见 [事实抽象](./09-fact.md)） |
| t0, t1 | 起止 |
| 任务圈定方式 | 按完成 / 按发布 / 按活跃 |

### 车辆时间片

第二批运力发挥类指标需要。

| 字段 | 说明 |
|------|------|
| run_id, agent_id, start, end | 连续状态起止 |
| state | 空闲 / 载货行驶 / 空驶 / 等待 / 充电 / 休息 |

### 事件

| 字段 | 说明 |
|------|------|
| run_id, ts, type | 运行、时刻、类型 |
| task_id, agent_id | 可选关联 |
| attrs | 可选：SoC、充电位 ID 等 |

## 2. 必须埋点的事件

| 事件 | 何时 | 写入 |
|------|------|------|
| 任务发布 | 进入调度 | 发布时间 |
| 任务分配成功 | 分配完成 | 分配时刻、车辆 |
| 任务完成 | 业务确认完成 | 完成时刻、状态 |
| 任务取消或失败 | 发生时 | 对应时刻与状态 |
| 车辆状态变化 | 状态切换 | 时间片 |
| 开始/结束充电 | 进桩与离桩 | 充电会话；可选 SoC；是否打断业务须可判定 |
| 抵达/离开休息点 | 无任务回休息点与被召回 | 休息会话 |
| 人工介入 | 需人处理 | 介入事件 |
| 故障 / 求助 | 发生时 | 对应事件 |

缺发布时间或完成时间，则第一批吞吐与完成率不上线。

---

## 3. 指标计算接口

```text
compute_metrics(run_id, t0, t1, window_type, metrics) -> 结果列表

每条结果至少含：指标编号、数值、单位、时间段、任务圈定方式、样本量、
（完成率场景）进行中任务数
```

同组参数反复计算应一致。起止非法或时间段过短时返回错误，不返回假吞吐。

---

## 4. 公式

语义见 [事实抽象](./09-fact.md)，叙述见 [L-Joint](./08-l-joint.md)。

- **吞吐量：** 时间段内完成数 / 时间段长度（建议任务数/小时）  
- **完成时延：** 时间段内完成 → 对 \(C-r\) 算均值与分位  
- **超时率、完成率：** 有截止才算超时率；完成率：时间段内发布 → 结束时刻结算 → 在结算集上计算  
- **人工介入：** 时间段内介入事件数

## 5. 产品统计页模块

| 模块 | 做什么 |
|------|--------|
| 时间段选择 | 班次预设、自定义起止，或绑定运行 |
| 第一批指标卡 | 吞吐、时延均值/P95、完成率、介入；有截止再加超时率；标明时间段与单位 |
| 说明脚注 | 一两句说明数的是哪批任务 |
| 第二批 | 时延分布、使用率与空驶/等待等 |

仿真器：每次试跑一次运行，默认整次运行为时间段；对比时对齐时长与任务到达过程。诊断类指标复用同一接口、不同指标编号。

---

## 6. 验收

1. 第一批结果含时间段与任务圈定方式。  
2. 换班次后吞吐、超时率变化，可手算抽检。  
3. 未结束运行中，截止未到的未完成任务不进完成率分母。  
4. 未选时间段时不展示吞吐量。  
5. 算法诊断类只出现在仿真器报表。

## 7. 本阶段不做

甲方综合打分、诊断指标默认进客户统计页。
