3.5 节点系统：Point 与 Node
在 USP 架构中，点不仅代表位置，更代表机器⼈的“状态ˮ与“朝向ˮ。
Point (物理点 / 视图点)
定义：地图上的⼀个⼏何坐标点 (x,y)。
层级：属于前端视图层（View Layer）。
作⽤：它是⽤户在界⾯上看到的“路⼝ˮ或“站点ˮ，⽤于构建可视化的地图⾻架。
Node (逻辑节点 / 拓扑点)
定义：路径规划算法（如 Dijkstra/A*）中使⽤的最⼩图元单位。它不仅包含坐标信息，还包含⾓度/朝向信息。
映射关系 1 Point ：N Nodes)：
⼀个 Point 对应多个 Node。具体数量取决于前端的分辨率设置。
架构逻辑：系统将⼀个物理点周围的 360° 空间进⾏切分。设定精度为 1 度（degree）对应 1 个 Node。
极限容量：因此，⼀个 Point 最多可以裂变为 360 个 Node。
业务意义：这种设计使得同⼀物理位置，如果机器⼈朝向不同（例如 0° 进⼊和 90° 进⼊），在算法眼中即为两个完全
不同的“节点ˮ。这是实现复杂路径避让、旋转控制和⾼精度对接的算⼒基础。

映射关系 1 Line ：Max 4 Edges)：

👉⽰例：⼀条双向的 Line A to B，在算法层最多对应以下 4 条 Edge：
Forward A  B：⻋头朝前（前进），从 A 开到 B。
