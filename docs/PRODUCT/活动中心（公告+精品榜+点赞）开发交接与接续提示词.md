## 2. 已锁定的口径（改需求前先看这里）

| 议题 | 结论 |
|---|---|
| 榜单排序依据 | **新建 `task_likes` 表**做点赞，按点赞数倒序（不蹭现有其他计数） |
| 榜单统计范围 | **只统计已归档工单**（`status = 'archived'`） |
| 公告维护方式 | **直接做后台 CRUD**（运营自助发布/下线/置顶），前台只读 |
| 公告条语义 | **只常驻展示一条生效公告，不轮播** |
| 无公告时 | 公告条**不渲染任何内容**（不占位、不留空条） |
| 接口失败 | 公告条 / 点赞均为**增强项，静默降级**，不打断主流程 |

## 4. 接口契约（照此对接，勿改字段名）

### 4.1 公告

| 方法 | 路径 | 权限 | 返回 |
|---|---|---|---|
| GET | `/api/announcements/active` | 登录 | `{ item: Announcement \| null }`（生效的一条；无则 `null`） |
| GET | `/api/announcements?skip=&limit=` | 登录 | `{ total, items: Announcement[] }`（仅已发布） |
| GET | `/api/admin/announcements?status=&keyword=&skip=&limit=` | `frontend:admin:announcement:manage` | `{ total, items }` |
| POST | `/api/admin/announcements` | 同上 | `{ ok, item }` |
| PUT | `/api/admin/announcements/{id}` | 同上 | `{ ok, item }` |
| POST | `/api/admin/announcements/{id}/publish` \| `/offline` | 同上 | `{ ok, item }` |
| DELETE | `/api/admin/announcements/{id}` | 同上 | `{ ok, id }` |

统一排序：`is_pinned desc → published_at desc → id desc`。

### 4.2 点赞 / 榜单

| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/tasks/{task_id}/like` | `{ ok, task_id, liked, like_count }` |
| POST | `/api/tasks/{task_id}/like` | 同上（`liked=true`），幂等（`ON DUPLICATE KEY UPDATE created_at`） |
| DELETE | `/api/tasks/{task_id}/like` | 同上（`liked=false`），幂等（未点赞影响 0 行） |
| GET | `/api/tasks/featured?limit=10` | `{ total, items: FeaturedTicket[] }`，只含已归档工单 |

`FeaturedTicket`：`id / title / status / like_count / is_liked / project_name / created_by / created_at / archived_at`。

## 5. 陷阱与注意事项（反复踩过，务必记住）

1. **静态路径必须前置注册**：`GET /featured` 必须定义在贪婪路由 `GET /{task_id}` 之前，
   否则 `featured` 会被当成 `task_id` 解析 → 422。新加静态子路径时同理。
2. **后台鉴权依赖有两个同名函数**：`backend/app/modules/admin/api/auth.py:37` 的
   `get_current_active_user_from_token` 与 core 里的同名函数。测试里做 override 时
   **两个依赖都要覆盖**，否则 401。
3. **点赞按钮不能放在详情页操作按钮行**：该行只在非终态显示，而精品榜只含已归档工单，
   因此点赞**独立成行**常驻标题下（`TaskDetailPage.tsx:1704`）。
4. **迁移脚本按项目约定仅本地保留、不提交**（远端专人执行迁移）；且**必须幂等**
   （启动时 `create_all` 可能已建表）。
5. **权限常量放 `api/*.ts` 导出**，不要在入口页为拿一个字符串把整页拖进首包。
6. **前端测试禁止断言类名**：用 `data-testid` / `getByRole` / `aria-*`。
   后台列表页的状态 Tag 文案与筛选下拉同名，断言要 `within()` 限定卡片范围（已踩过）。
