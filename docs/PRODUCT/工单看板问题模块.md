# 工单看板问题模块

## 入口与权限

后台管理 → 工单数据看板，现有统计卡片下方增加「问题模块」。源数据没有可靠的系统项目 ID，因此首期仅具备 `backend:project:all` 权限的用户或管理员可见；接口同时校验权限，不能通过前端传项目参数绕过。

## 数据源

使用服务现有数据库连接，不硬编码库名，不新建业务表，不修改镜像同步流程。2026-10-13 已只读核对本地 `helpdesk.external_record`：`source_key = 'zl_question_robots'` 共 463 条镜像记录，包括空行。

`values` 的真实字段：

| JSON 字段 | 用途 |
| --- | --- |
| `上报时间(自动生成，无需填写)` | 按上报日期筛选，兼容简写字段 `上报时间` |
| `问题描述` | 问题原文 |
| `问题解决描述` | 解决描述原文；空值不推断为未解决 |
| `车辆编号和车型` | 合并原文展示，不猜测拆分；兼容独立车辆编号、车型字段 |

源数据包含 `2026/7/29 2:54 PM` 等非补零、12 小时制格式，以及 `46261.767245` 这样的 Excel 日期序列值，按北京时间解析。另兼容 ISO、24 小时制、日期、10 位秒时间戳和 13 位毫秒时间戳。无时区的源上报时间按北京时间解释；带时区时间转换为北京时间。只有日期的记录不虚构具体时刻。

## 接口

`GET /api/admin/dashboard/questions?report_date=2026-09-28&page=1&page_size=20`

参数：`report_date` 必填，格式 `YYYY-MM-DD`；`page` 从 1 起，默认 1；`page_size` 默认 20，最大 100。非法日期或分页返回 422，无查看权限返回 403。

响应结构：`{code: 0, data: {report_date, total, page, page_size, items, last_sync_at}}`。单条只返回 `record_id`、`reported_at`、`problem_description`、`solution_description`、`vehicle_info`、`vehicle_number`、`vehicle_model`，不返回其他源字段。

数据库先限定数据源并预筛选目标日期及相邻日期、时间戳区间，再统一解析时区、精确过滤、排序、统计和分页。相邻日期用于覆盖跨时区记录；不沿用原始镜像查看接口的 1000 条上限。当前按日候选记录在服务内精确分页，数据量增长后可评估增加规范化上报时间列及索引。

按上报时间降序排列，同时间按镜像 ID 降序保证分页顺序稳定。缺少或无效上报时间的记录不使用入库时间替代。`last_sync_at` 为该数据源镜像的最近 `pulled_at`，仅供同步提示，不参与日期筛选。查询只读，不触发外部同步。

## 页面行为

- 默认北京时间今天；可切换单日、回到今天、手动刷新。
- 每页 20 条，加载更多追加；切换日期重置第一页并丢弃旧请求结果。
- 长描述超过三行可展开收起，保留换行，按纯文本展示源内容。
- 查询失败显示错误和重试，不伪装成空数据；追加失败保留已有记录。
- 独立于原有统计接口加载，不使用通用请求缓存，按账号切换重建组件。
- 历史日期展示该天上报记录的当前最新内容，不提供历史内容快照。
