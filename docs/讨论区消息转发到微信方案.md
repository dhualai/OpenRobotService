# 讨论区消息转发到微信方案

> 状态：**客服消息方案已废弃并移除（2026-08）**；改用**长图 + H5 链接 + 微信原生分享**方案（规划中）。

---

## 一、已废弃方案：公众号客服消息（已移除）

### 废弃原因

原方案通过微信公众号客服消息（`/cgi-bin/message/custom/send`）按 `open_id` 单发，存在三个无法绕过的硬限制：

| 限制 | 说明 |
|------|------|
| **48h 互动窗口** | 接收人超 48h 未与公众号互动即收不到（`errcode 45015`），无法绕过 |
| **不能发微信群** | 公众号无"向指定群发消息"接口，群发接口面向全部粉丝 |
| **open_id 绑定难** | 业务账号需手动绑定 open_id，但用户无法自行获取自己的 open_id（微信不向用户展示），导致绑定率极低或填错 |

### 已移除的代码

- 前端：`ForwardToWechatDialog.tsx`、`api/forward.ts`（整文件删除）
- 前端：`DiscussionPanel.tsx` 移除"转发到微信"菜单项与弹窗引用
- 前端：`global.css` 移除 `.detail-forward-*` 样式段
- 后端：`task.py` 移除 `forward-targets` / `forward-to-wechat` 接口及 `_resolve_wechat_openid` / `_strip_html_for_wechat` / `_build_task_detail_url` / `_describe_attachments_for_wechat` / `ForwardTarget` / `ForwardToWechatRequest` 等辅助代码
- 后端：`auth_routes.py` 移除 `/me/wechat-openid` 绑定/查询/解绑三个接口

### 保留（不动）

- `users.wechat_openid` 数据库字段：nullable，留着无害，避免迁移风险（未来若复用可直接用）
- `apply_user_wechat_openid_migration.py` 迁移脚本：幂等，留着无害
- `wechat_service.send_message_to_user` / `send_link_message_to_user`：仍被其他通知逻辑使用（如 `message.py` 群发通知），保留

---

## 二、新方案：长图 + H5 链接 + 微信原生分享（规划中）

### 核心思路

讨论区消息 → 前端 `html2canvas` 生成长图 → 上传 MinIO → 生成免登录 H5 页链接 → 用微信 JS-SDK 配置分享卡片 → 用户点右上角「…」原生转发到**群/好友/朋友圈**。

### 优势（彻底绕开旧方案三大死结）

| 对比项 | 旧方案（客服消息） | 新方案（长图+H5） |
|---|---|---|
| open_id 绑定 | 每人必须绑定 | **不需要** |
| 48h 窗口 | 超时收不到 | **无限制** |
| 发微信群 | 不支持 | **支持**（微信原生分享） |
| 接收人体验 | 公众号对话框收文本 | 微信里点链接看长图，可长按保存 |

### 现有基础设施（已就绪）

- ✅ `setupWechatShare`（`wechatJsSdk.ts`）：已实现微信原生分享卡片配置（title/desc/link/imgUrl），工单详情页已在用
- ✅ MinIO 存储 + `/api/tasks/files/{path}` 代理下载：已就绪，不要求登录（靠 object_path 不可猜测性保护）
- ✅ `minio_client.upload_bytes`：上传能力已有
- ✅ nginx 已配 `/p/app/`、`/p/api/`，域名 `usp.ep-zl.com` 已在公众号 JS 安全域名内
- ❌ 需引入 `html2canvas`（约 200KB，懒加载）
- ❌ 需新增免登录分享页路由（当前所有路由在 AuthGuard 下）

### 待开发改动

1. **前端·生成长图**：引入 `html2canvas`（懒加载），把讨论区最近 N 条评论 DOM 渲染成 PNG（`scale: 2` 提清晰度，限条数防图过大）
2. **后端·分享接口**：`POST /api/tasks/{id}/comments/share-snapshot` → 接收长图上传 → 存 MinIO → 返回 H5 链接
3. **前端·免登录分享页**：新增路由 `/share/snapshot/:token`（不走 AuthGuard），展示长图 + 工单基本信息，进入时 `setupWechatShare` 配置分享卡片
4. **讨论区入口**：长按消息 → "生成分享图" → 生成长图 → 上传 → 引导用户点右上角「…」转发

### 难点与对策

| 难点 | 对策 |
|---|---|
| 分享页免登录安全 | 靠 token 不可猜测性保护（同附件 `/files/{path}` 策略，已验证可行）；token 可加时效 |
| 微信拦截外部链接 | 分享页在 `usp.ep-zl.com`（已配 JS 安全域名），微信不拦 |
| 长图过大/模糊 | 限最近 20 条评论；`scale: 2`；超长提示"仅最近 N 条" |
| html2canvas 体积 | 懒加载，仅点分享时动态 import |
| 聊天记录里的图片 | `useCORS`；附件图走后端代理同域，无跨域问题 |
