# 责任模块树 · 扩展设计草案（基于旧画像 103 模块）

> 目的：根据用户旧 `responsibility_modules` 画像，倒推出新责任树应补充/细化的功能节点，
> 使**派单能精确到负责的工程师**（尤其路径规划类这类复合功能）。
> 设计原则：功能作为叶子粒度，细化即更多叶子功能 + 独立负责人 + 独立关键词。
> 开发流程角色（测试/项目/需求/版本等）单列「开发流程支撑」界面，不进派单主流程。
