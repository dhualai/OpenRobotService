# AI Review 误报台账（观察期）

> 观察期：上线起 2 周或 ≥20 个真实 PR（先到为准）。
> 每条意见花 10 秒做三态判定；观察期结束由小D汇总，达标线见下表。
>
> **算误报**：问题实际不成立（上下文已有解释 / 风格偏好 / 规则不适用）。
> **不算误报**：问题成立但人工接受风险（报对了，决定不改）。

## 达标线与出口决策

| 分档 | 达标线 | 不达标动作 |
|---|---|---|
| 高危（推企微） | 误报率 < 30%，回放集 5 个历史事故至少抓出 3 个 | 收紧 prompt 保守化，宁漏勿扰 |
| 建议关注（仅评论） | 误报率 < 50% | 高频误报模式写进忽略规则 |
| 整体出口 | 连续两周达标 | 维持现状；再议二期（自动触发深化） |
